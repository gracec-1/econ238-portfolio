LCOE Versus an Electricity System

What changes when we move from comparing the average cost of electricity technologies to building a system that must meet actual demand every hour?

The question: Does a low Levelized Cost of Electricity (LCOE) automatically mean a low-cost electricity system?

1. Start with LCOE

Levelized Cost of Electricity (LCOE) is commonly used to compare the average cost of generating electricity from different technologies. It is useful for a technology-level comparison, but it does not by itself show whether electricity is available at the exact time consumers need it.

Figure 1. LCOE comparison. Values are the arithmetic midpoints of Lazard's 2026 unsubsidized LCOE ranges: utility solar PV $40–98/MWh, onshore wind $37–99/MWh, and gas combined cycle $44–136/MWh.

2. Electricity demand changes every hour

An electricity system does not simply need electricity over the course of a year. It must provide enough electricity when people and businesses are actually using it. To make that visible, I use an actual hourly AEP load series from the public PJM-derived Hourly Energy Consumption dataset.

Figure 2. Actual hourly AEP electricity demand for a 24-hour period, December 31, 2004 01:00 through January 1, 2005 00:00. Demand is measured in MW.

3. Add the hourly constraint

Now consider a simple system with solar, wind, and gas. Solar and wind have variable hourly availability. Gas is dispatchable and fills the remaining gap. The important constraint is:

Solar + wind + gas ≥ demand in every hour.

Figure 3. Illustrative hourly system using the actual demand series. Solar and wind profiles are stylized availability assumptions; gas supplies the residual demand. This is an illustration of the system constraint, not a forecast of actual renewable generation in the AEP zone.

4. What changes?

LCOE comparison

Question: How expensive is electricity generated by a technology on average?

  • Compares individual technologies.
  • Uses an average generation-cost measure.
  • Does not by itself require generation to match demand hour by hour.

Electricity system

Question: How can we provide enough electricity when it is needed?

  • Uses hourly demand.
  • Requires supply to meet demand in every hour.
  • May require dispatchable generation, storage, transmission, or other resources.

Figure 4. Illustrative 24-hour cost proxy using the same LCOE midpoints. This is not a full least-cost system model: it excludes fixed capital costs, storage, transmission, reserves, and other system costs.

The main lesson: LCOE and system cost answer different questions. A technology can have a low average LCOE while the system still needs other resources to cover hours when that technology is not producing enough.

5. Assumptions and limitations

  • Demand: actual hourly AEP observations from the public PJM-derived dataset.
  • LCOE: Lazard 2026 unsubsidized ranges; this exhibit uses each range's midpoint only as a simple comparison value.
  • Solar: capacity set to 75% of the example day's peak demand; hourly availability is stylized to represent daylight production.
  • Wind: capacity set to 75% of the example day's peak demand; hourly availability is stylized around a 30% capacity factor.
  • Gas: supplies the residual demand after solar and wind.
  • Storage: not included.
  • Transmission and reserve margins: not included.
  • Cost calculation: the final chart is a simplified LCOE-weighted generation proxy, not a full power-system optimization.

6. Data and sources

Hourly load data: AEP_hourly.csv. The dataset contains the variables Datetime and AEP_MW and contains more than 120,000 hourly observations.

LCOE: Lazard, Levelized Cost of Energy+ Version 19.0 (2026).

Dataset background: The AEP series is part of the public Hourly Energy Consumption dataset based on PJM electricity-demand data. The repository documentation identifies the series as hourly AEP electricity consumption measured in MW.
